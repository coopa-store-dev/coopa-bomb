# 库巴传炸弹

全家格斗版的传炸弹:选一个家人,把炸弹扔给对面,攒气放必杀和超必杀。
引信多长谁也不知道,炸在谁手里谁输这一回合;先赢 3 回合的人赢。

- **和电脑打**:一个人也能玩,依次打另外三个家人(简单 → 普通 → 厉害),三关都赢就通关,选人页这个人头上戴皇冠。
- **两人联机**:两个人各拿一张 Coopa 卡,面对面对战。

## 怎么玩

- **● 扔**:箭头左右来回摆,在绿区里按 ● 才扔得过去,正中间的金色是「完美」;扔歪了炸弹会弹回来。炸弹越烫,箭头摆得越快。
- **能量**:每人 4 格。完美 +1,被对方的招打中 +1,输一回合 +2。
- **▲ 必杀**(2 格)和 **▼ 超必杀**(4 格):炸弹在手里时才能放,放了炸弹一定扔中。

| 角色 | ▲ 必杀 | ▼ 超必杀 |
|---|---|---|
| 库巴 | 弹弓:对方晕 1.5 秒扔不了 | 影分身:对方那边两个炸弹,只有一个是真的 |
| 库巴爸爸 | 火箭快递:引信在对方手里烧两倍快 | 铁笼:对方要按 ● 8 下砸开笼子 |
| 库巴奶奶 | 念叨:对方的箭头变快、绿区变小 | 锅盖神功:下一次炸在奶奶手里时,锅盖把炸弹崩回去 |
| 库巴爷爷 | 老花镜:自己接下来 3 次瞄准变慢变宽 | 太极推手:对方下一次扔过来,自动推回去 |

- 刚接到炸弹的半秒里扔不回去;放超必杀时两张卡一起放特写,对面的引信先停一停。
- 炸弹越来越红、嘀嗒越来越快——不过它什么时候炸,看颜色是看不出来的。
- 联机断线不怕:这一回合重来,比分、能量都留着。

## 开发

需要外壳接口 2(`kit_api = 2`,`kit_link.h`)和 SDK 4。

- `make -C tests`:规则、招式、联机、存档、电脑对手的宿主测试;`test_balance` 打几千场统计数值。
  给 `COOPA_SHELL=外壳目录` 时再测一遍语音解码。
- `tools/gen_lines.py`:重新生成四个角色的语音(要 edge-tts 和 ffmpeg)。
- `tests/sim_cpu.py`、`tests/sim_duo.py`:在桌面模拟器里和电脑闯关、两张卡对战。
- `coopa run`:浏览器里玩;打开它打印的 `duo.html` 可以一页两张卡对战。
- `coopa check`:和商店一样的检查。
